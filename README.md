# 🤖 AI-Powered Recruitment & Hiring Platform

An end-to-end AI-powered recruitment automation platform built using **n8n**, **Groq AI**, **Google Workspace**, and **JavaScript**.

---

## 📌 Project Overview

This platform automates the complete recruitment lifecycle, from candidate registration to offer letter generation.

The system reduces manual effort, speeds up hiring, and assists HR teams with AI-powered resume evaluation.

---

## 🚀 Features

- AI Resume Screening
- Resume Parsing
- HR Approval Workflow
- Interview Scheduling
- Google Calendar Integration
- Gmail Notifications
- Offer Letter Generation (PDF)
- Google Drive Storage
- Recruitment Analytics Dashboard
